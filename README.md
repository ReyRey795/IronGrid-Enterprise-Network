# IronGrid — Enterprise Network Engineering Lab

## Project Overview

IronGrid is a hands-on enterprise networking project built using Cisco Packet Tracer. The goal is to design, configure, secure, and troubleshoot a simulated company network while documenting the engineering process.

## Technologies

- Cisco Packet Tracer
- TCP/IP Networking
- Cisco Routers and Switches
- VLANs and Subnetting (planned)
- Routing and Network Security (planned)
- Git and GitHub

## Lab 01 — Basic LAN Connectivity

**Objective:** Establish communication between two computers connected through a Cisco 2960 switch.

**Configuration:**

| Device | IPv4 Address | Subnet Mask |
|---|---|---|
| PC-01 | 192.168.10.10 | 255.255.255.0 |
| PC-02 | 192.168.10.11 | 255.255.255.0 |

**Result:** Successfully verified connectivity between PC-01 and PC-02 using the `ping` command.
